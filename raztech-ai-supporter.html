Settings & Help

Data connection

Public market data connection has not been checked yet.

No API key is required for public market data. The browser may block API requests due to network, host, or CORS restrictions. If requests fail, use a trusted backend proxy rather than placing secret keys in this HTML.

What this analyzer can and cannot do

  • Can: read public candles/ticker data when the API is reachable, calculate common indicators, identify selected candle patterns, produce transparent rule-based signals, and run a limited historical simulation.
  • Cannot: guarantee a 90% win rate, predict every market move, see your private Bitget account, or place/close orders.
  • AI note: the analysis here is deterministic technical logic, not a trained AI model or an expert human trader. A true AI explanation service requires a backend and a model API; never put a secret model key in front-end JavaScript.
  • Timezone: chart candle times are displayed in your browser's local timezone. Verify Bitget's candle timestamp conventions when comparing with trade history.
  • Privacy: journal records stay in this browser's localStorage unless you export them.

Optional live execution later

Do not add real order execution until the signal engine has been tested. If you later build it, use a secure backend, least-privilege API keys, withdrawals disabled, explicit user confirmation, server-side risk limits, duplicate-order protection, and an emergency stop. Start with Bitget demo trading.
