Strategy rules: enter a simulated long position when SMA 20 crosses above SMA 50; exit when SMA 20 crosses below SMA 50. The signal is calculated using a candle close, and simulated execution occurs at the next candle open. Only completed trades count toward the reported win rate. The final open position, if any, is valued at the latest close.

Safety and Limitations

This is an educational tool using public market data. It does not access your exchange account or place orders. Historical results are not predictions. This basic backtest excludes fees, spread, slippage and market impact, so actual results could be worse. It uses only the candles loaded into the app.
